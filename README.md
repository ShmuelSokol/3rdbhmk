# Third Beis HaMikdash

Explore the measured reconstruction in a downloadable Windows walkthrough, including ground walking and a white-dove flight mode.

**[Download the Windows preview](https://github.com/ShmuelSokol/3rdbhmk/releases/tag/walkthrough-09-preview)**

Download both **Mikdash-Walkthrough-09-App.zip** and **Mikdash-Walkthrough-09-Data.zip**, extract both into the same folder, then open **MikdashCourtyardV3.exe**. GitHub's Source code archives are for developers.

[How to install and play](unreal/DOWNLOAD.md) · [Current preview limitations](unreal/MikdashCourtyardV3/RELEASE-NOTE-Walkthrough-09.md)

This is an evolving development preview. Visual detail, source accuracy, population behavior and other features remain under review. The game runs on the player's own Windows PC; the developer's computer does not need to remain online.
