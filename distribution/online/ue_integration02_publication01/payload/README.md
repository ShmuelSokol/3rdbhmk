actual integration01 project. It leaves the frozen 180-file closure unchanged.

checks it during stopped ownership, and revokes it on shutdown. ConfigureRemote
now requires FindLease for the authority's immutable exact process Owner and
installs MakeOwnedSettingsCallback itself. Missing lease/provider still refuses;

invoked by the module. A later single parsed-bootstrap handoff to the receiver
must replace that separate read before listener activation. Settings06's external
