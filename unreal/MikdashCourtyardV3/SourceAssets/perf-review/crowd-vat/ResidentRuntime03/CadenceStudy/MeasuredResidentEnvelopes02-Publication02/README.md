# Reproducible resident VAT body measurements
Archived, conditional source-pixel evidence for two variants, 192 idle and72 walk frames each. This is not a new playable build, native asset validation, cooked GPU proof or controller adoption.

Run `python -B replay.py` with Python3.12.14 and NumPy2.3.5. All inputs are relative to this folder; no engine, original project, network or executable is needed. Tests and complete study13 results (including witnesses and pixel digests) must match exactly. The original evidence receipts retain original hashes and are historical; portable code hashes are separately recorded in manifest.json.

Read both contracts before using bounds. Idle UV2 correspondence and Wrap addressing remain explicit source-derived premises. No UE packages, engine code, private logs, failed exports or local Saved state are included. Data are project-authored posed geometry and position textures, not third-party human images. Provenance records omitted dependencies and archived receipt identities.
